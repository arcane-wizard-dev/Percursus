# Percursus

[![GitHub Release](https://img.shields.io/github/v/release/arcane-wizard-dev/Percursus?color=blue&logo=github&cacheSeconds=600)](https://github.com/arcane-wizard-dev/Percursus/releases) [![GitHub Release Date](https://img.shields.io/github/release-date/arcane-wizard-dev/Percursus?color=blue&logo=github&cacheSeconds=600)](https://github.com/arcane-wizard-dev/Percursus/releases)

_Master every course._

Percursus is a World of Warcraft addon that tracks performance in supported races and makes it comparable, including Skyriding, Skyrocketing, and Breakneck (D.R.I.V.E.). It shows the progress live during a race and gathers times and targets in clear overviews.

> ⚠️ **Important!** This addon requires **Arcane Wizard: Library**. See Installation & Quick Start for installation details.

## Key Features

**Race Tracker** - Shows the progress during a race in different display modes that keep the timing goals in view.

**Race Time Overview** - Shows race times and targets for the current area in an overview, making it easier to compare results.

**All Races Overview** - Lists times and targets across supported races in an organized overview that keeps track of racing progress.

## Features

Individual features and display options can be configured in the addon settings. Percursus supports an account profile and character profiles.

### Race Tracker

* Three modes for the Race Tracker are available: current race time, countdown to medal time (gold or silver), and countdown to the personal best time.
* Different backgrounds can be selected for the Race Tracker.
* Optionally shows the race speed during Skyriding races.
* The Race Tracker can be moved anywhere on the screen.

### Race Time Overview

* Current Race and Zone tabs show personal bests and medal targets.

### All Races Overview

* All Races provides an overview grouped by continent and zone.
* Both overviews offer table menus with filters, separators, and expand/collapse actions.

## Supported Languages & Flavors

* Languages: English, German, Russian, Chinese (Simplified)
* Flavors: Retail

## Installation & Quick Start

> **Required Dependency:** This addon requires **Arcane Wizard: Library**. If you install Percursus via the CurseForge client, the library will be downloaded automatically. If you install the addon manually, via Wago, or through another third-party updater that does not resolve dependencies, you must download and enable the library separately.

To manage the addon, type the following commands in chat and press Enter:

* Type `/per` or `/percursus` to access the addon options menu.
* Type `/per changelog` or `/percursus changelog` to open the changelog.
* Type `/per overview` or `/percursus overview` to manually display the All Races Overview.
